# advanced-networking-campus-lab
Campus Area Network design and implementation using Cisco Packet Tracer 
Campus Area Network (CAN) Project

Project Overview

This project involves designing, configuring, and testing a Campus Area Network using Cisco Packet Tracer. The network will connect three two-story academic buildings and an outdoor common area.

Network Requirements

The campus network will include:

Wired and wireless connectivity

Departmental VLANs and IPv4 subnetting using CIDR/VLSM

Inter-VLAN and inter-building routing

Centralized servers in Building A

Internet connectivity using NAT/PAT

Firewall protection and a DMZ

Network security and connectivity testing

Tools

Cisco Packet Tracer
